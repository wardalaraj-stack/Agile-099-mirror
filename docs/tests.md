# Tests

Test environment depends on `src/`.

## Commands

Run commands from project root.

`python -m tests.test_menu`

`python -m tests.test_board`

`python -m tests.test_snake`

`python -m tests.test_movement`

`python -m tests.test_speed`

`python -m tests.test_food`

`python -m tests.test_collision`

Press escape to exit.
