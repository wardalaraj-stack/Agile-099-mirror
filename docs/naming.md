# Naming

We follow PEP 8, the official Python style guide.
https://peps.python.org/pep-0008/

## Conventions

| Component | Convention |
|---|---|
| Files | snake_case |
| Functions | snake_case |
| Methods | snake_case |
| Variables | snake_case |
| Classes | PascalCase |
| Constants | UPPER_SNAKE_CASE |
| Packages | lowercase |

Use descriptive names, avoid unnecessary abbreviations and follow these conventions when creating or modifying code.
